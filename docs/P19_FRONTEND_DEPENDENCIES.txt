Install P19 frontend quality dependencies from:

F:\My_Projects\CricIntel\cricintel\frontend

Command:

npm install -D vitest @testing-library/react @testing-library/jest-dom @testing-library/user-event jsdom @playwright/test wait-on

This updates the existing package.json and package-lock.json.
Do not replace the existing package.json with a partial generated file.

Then install the Playwright browser once:

npx playwright install chromium
